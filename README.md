# Guru Punvaanii - Master SEO Audit & Command Center

High-performance, enterprise SEO Audit Engine and Interactive Dashboard for Guru Punvaanii Properties.

## 🚀 Features
- **360° Technical SEO Audit**: Canonical tags, XML sitemap validation, meta robots, indexability checks.
- **On-Page SEO Analyzer**: Title tags, meta descriptions, semantic headings hierarchy (H1-H3).
- **Schema Studio**: Structured data & JSON-LD validation (RealEstateAgent, SingleFamilyResidence, FAQPage).
- **Media Engine**: Image alt tag audit, aspect ratios, responsive layout checks.
- **Live URL Scanner**: Instant on-demand audit for any live webpage or XML sitemap.
- **30-Day Developer Action Plan**: Interactive prioritized implementation checklist.
- **Export Capabilities**: Complete Excel audit report generation.

## 🛠️ Tech Stack & Deployment
- **Frontend**: Vanilla HTML5, Modern CSS (Glassmorphism & Light/Dark themes), Chart.js
- **Backend / API**: Python Serverless Functions (`api/audit.py`, `api/data.py`)
- **Deployment**: Optimized for 1-click **Vercel** deployment with `vercel.json` and `@vercel/python`.

## 📦 Run Locally
```bash
python server.py
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
